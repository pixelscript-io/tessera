# Using Kbd

A key or a shortcut, shown as it is on a keyboard.

- Put one key in each `Kbd`, and join a shortcut with plain text: `Ctrl` + `K`.
- Use the real key name the person sees, such as `Esc` or `Enter`, and spell it the way the platform does.
- `size="sm"` fits inside a line of text or a menu item.

```tess live
<template>
  <p>Press <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> to search, or <Kbd size="sm">Esc</Kbd> to close.</p>
</template>
```
