Read SPEC.md before any work. Build one milestone at a time (section 15). Do not start a milestone until the previous one's acceptance criteria pass. Ask before adding any runtime dependency.

Never set a version of 1.0.0 or higher, in any package, doc or release note. Versions stay `0.MINOR.PATCH` (0.9, then 0.10, 0.11 and so on, with no limit) until the author says, in chat, that 1.0 is declared. A test and a prepublish check enforce this; do not edit them to get around it.
