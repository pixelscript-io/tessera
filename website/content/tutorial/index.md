# Tutorial

Nine short steps from an empty project to a themed, routed page with a token-enforced component. Each step ends with a check you can run, and every code sample on these pages is compiled by the docs test suite, so what you read is what works.

You need a project from the [Quick start](/quick-start). Every command below runs in its folder.

1. [A first component](/tutorial/01-first-component)
2. [State and templates](/tutorial/02-state-and-templates)
3. [Props and variants through a contract](/tutorial/03-contracts)
4. [Styling with tokens](/tutorial/04-styling)
5. [Theming and dark mode](/tutorial/05-theming)
6. [Pages and routing](/tutorial/06-pages)
7. [Layouts](/tutorial/07-layouts)
8. [Accessibility tests](/tutorial/08-accessibility)
9. [Keeping it checked](/tutorial/09-checking)

The interactive in-browser version of this tutorial comes with the playground, which is deferred.
