# @pixelscriptio/tessera

A design-system-first frontend framework: tokens, accessibility, variants and docs are built in and enforced at compile time.

```bash
mkdir my-app && cd my-app
npm init -y
npm install @pixelscriptio/tessera
npx tessera init
npm run dev
```

Status: early development. See the docs for the guide, the tutorial and the reference.
